# CLI Reference

## jig --list
List all registered agents/skills.

## jig --chat
Interactive chat mode. Type prompts, get agent responses.

## jig --run <prompt>
Run a single prompt through the SOP pipeline.

## jig eval <dataset> --report <path>
Run evaluation dataset.

## Environment
- `JIG_SKILLS_DIR` — skills directory path
- `JIG_CONFIG` — config file path
